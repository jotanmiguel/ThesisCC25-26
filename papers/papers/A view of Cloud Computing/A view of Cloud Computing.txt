Goal: clarify concepts, analyze advantages, identify obstacles.

Características essenciais que distinguem a nuvem de um datacenter tradicional (as talked on "The NIST Definition of Cloud Computing"):
	Elasticity → "infinite" resources, avail. on demand.
	No → não need to buy/rent hardware.
	Pay-as-you-go → Only pay the resources you are using, instead of renting per month with a fixed value per month.

Economia da Cloud
	Problemas resolvidos:
		Overprovisioning → excesso de recursos = desperdício.
		Underprovisioning → falta de recursos = perda de utilizadores e receitas.

	Conceito de custo-associatividade: usar 1.000 máquinas por 1h = 1 máquina por 1.000h (útil para batch jobs).
